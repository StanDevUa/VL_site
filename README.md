Технічна документація — `tech_specs.md` (ТЗ) та `architecture.md` (архітектура, схема БД, план сторінок і адмінки).

## Стек

Next.js (App Router) + TypeScript, PostgreSQL + Prisma, Tailwind CSS v4, next-intl, Auth.js.

## Локальна розробка

Базі даних живе на віддаленому сервері, доступ — через SSH-тунель. Перед `npm run dev` / будь-якою Prisma-командою тунель має бути піднятий в окремому терміналі. Сама команда (хост, порт, обліковка) навмисно не в репозиторії — вона в коментарі на початку локального `.env` (файл не в git, оскільки репозиторій публічний). Скопіюй команду звідти й запусти в окремому терміналі — тримає з'єднання відкритим, не закривай термінал, поки працюєш.

Далі в іншому терміналі:

```bash
npm install     # якщо ще не встановлено
npm run dev     # http://localhost:3000
```

## Prisma

```bash
npm run db:generate   # згенерувати Prisma Client після зміни schema.prisma
npm run db:migrate    # створити й застосувати нову міграцію
npm run db:studio     # відкрити Prisma Studio (перегляд/редагування даних у браузері)
```

## Мультимовність

- `uk` (за замовчуванням, без префіксу), `en` (`/en/...`), `ru` (`/ru/...`)
- Інтерфейсні рядки — `messages/{uk,en,ru}.json`
- Контент з адмінки — пласкі колонки на мову в моделях Prisma (`nameUk`/`nameEn`/`nameRu` тощо), з фолбеком на `uk`, якщо переклад не заповнено
